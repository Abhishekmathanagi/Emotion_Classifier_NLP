# 🎭 Emotion Classifier

A text-based emotion classifier built with **TF-IDF + Logistic Regression** (scikit-learn), served through an interactive **Streamlit** app.

Type any sentence and the app predicts the emotion behind it — joy, sadness, anger, fear, love, or surprise — along with a confidence breakdown for every class.

## Demo

> `"I can't believe I got the job, I'm so excited!"` → **😄 Joy**

## Features

- Custom text-cleaning pipeline (lowercasing, punctuation/number/URL/HTML/non-ASCII removal, stopword filtering) with **no external data downloads required**
- Three models trained and compared: Bag-of-Words + Naive Bayes, TF-IDF + Naive Bayes, and TF-IDF + Logistic Regression (the one deployed)
- Per-emotion confidence bars, not just a single predicted label
- Shared preprocessing module used identically at training time and inference time, so what the model saw in training is exactly what it sees from user input

## Project structure

```
.
├── app.py                     # Streamlit app (UI + inference)
├── emotion_preprocessing.py   # Shared text-cleaning pipeline (training + app)
├── train_model.py             # Training script (.py version)
├── train_model.ipynb          # Training notebook (.ipynb version)
├── train.txt                  # Training data (text;emotion pairs)
├── requirements.txt           # Dependencies
├── tfidf_vectorizer.pkl       # Fitted TF-IDF vectorizer (generated by training)
├── emotion_model.pkl          # Fitted Logistic Regression model (generated by training)
└── label_map.pkl              # {label_id: emotion_name} mapping (generated by training)
```

## Getting started

### 1. Clone and set up a virtual environment

```bash
git clone <your-repo-url>
cd <your-repo-name>
python -m venv .venv
source .venv/bin/activate        # Windows: .venv\Scripts\activate
```

### 2. Install dependencies

```bash
pip install -r requirements.txt
```

### 3. Train the model

Produces `tfidf_vectorizer.pkl`, `emotion_model.pkl`, and `label_map.pkl`.

```bash
python train_model.py
```

Or open and run `train_model.ipynb` cell by cell if you prefer a notebook.

### 4. Launch the app

```bash
streamlit run app.py
```

Open the local URL Streamlit prints (usually `http://localhost:8501`).

## Dataset

Expects `train.txt` formatted as semicolon-separated `text;emotion` pairs, no header row:

```
i didnt feel humiliated;sadness
im grabbing a minute to post i feel greedy wrong;anger
i am feeling grouchy;anger
```

## Tech stack

- **scikit-learn** — TF-IDF vectorization, Logistic Regression / Naive Bayes
- **pandas** — data loading and manipulation
- **Streamlit** — web UI
- **Python** standard library (`re`, `string`) — text cleaning, no NLTK dependency

## Swapping in a different model

By default `train_model.py` saves the TF-IDF + Logistic Regression model. To deploy the Naive Bayes variant instead, edit the save step at the bottom of `train_model.py`:

```python
with open("emotion_model.pkl", "wb") as f:
    pickle.dump(nb2_model, f)   # was: pickle.dump(lr, f)
```

`app.py` requires no changes — it works with any model exposing `.predict()` / `.predict_proba()`.
